## 受け入れ基準の「確かめ方」

このアプリは Google Apps Script（GAS）で動くため、受け入れ基準（AC）ごとに確かめ方を決めています。

- **自動テスト**：判定・計算・変換など、答えが 1 つに決まるもの。`npm run test` で PC の中で確かめる
- **確認用 URL**：画面の見た目・操作、スプレッドシートへの保存。確認用 URL（末尾が `/dev`）を開いて目で確かめる

---

## 制約・前提（プロジェクト全体）

- 画面は **1枚** のみ（ページ遷移なし）
- **ログイン・外部 API を使わない**。データは自分の Google ドライブのスプレッドシートに保存する
- 公開範囲は **自分だけ**（`appsscript.json` の `webapp.access` = `MYSELF`）
- 非エンジニアが上から下まで追える **素直な構造**（判定の関数と、保存・画面を分ける）
- **締切・優先度などを後から足しやすい構造** にする（タスクの項目とシートの列を 1 か所で足せる）
- テストは **Vitest** を使う（PC の中だけで動く。Google には送らない）
